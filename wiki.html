Quick Start

Everything runs in the browser — nothing to install.

  1. Get a username and password from the admin (whoever's running the server).
  2. Open the game's link and log in.
  3. You'll land in the Hub — a shared space everyone spawns into after logging in.
  4. Walk up to the Travel button (bottom-right corner) to jump to any world. Pick the same one your friends picked and you'll land in the same game together — no codes to share.
  5. To come back to the Hub later, just reload the page (or reconnect with no map picked).
Your progress is saved automatically. Health, armor, ammo and weapons are tied to your account and restored the next time you spawn — even in a different room, even after closing the tab.

On phones/tablets, on-screen FIRE and JUMP buttons appear automatically — drag anywhere else on screen to look around and walk.

Modern corner HUD: type cl_modernhud 1 in the console to switch from the classic full-width status bar to a corner-anchored layout (face/health bottom-left, ammo/keys/powerups bottom-right) inspired by the 2021 rerelease. cl_modernhud 0 switches back. It's saved with your other settings, so you only need to set it once.

Console & Cheats

Press ~ to open the console and type any of these. They work in any room, against any mod that's loaded — including custom monsters/items from Copper or Fantasy Quake.

CommandWhat it does
godToggle invincibility.
noclipToggle walking through walls.
notargetToggle monsters ignoring you.
give h100Set health to 100 (any number).
give c100Set cells to 100. Also shells, nails, rockets.
give 2 … give 8Give a specific weapon (2 = shotgun, 3 = super shotgun, etc).
summon <classname>Spawn any monster, item or weapon a few steps in front of you. See Enemies & Items for classnames.
classlist <text>List every spawnable classname containing that text in the currently loaded mod — e.g. classlist monster_.
name "Yourname"Change your display name (normally set automatically from your login).
disconnectLeave the current room without closing the tab.
impulse 50Fantasy Quake only — cycle player class. See Mods.
Example: summon monster_ogre drops an ogre right in front of you. summon item_health drops a healthbox. Works with anything from classlist's output.

Mods

Horde Mode engine feature

Wave-based monster survival, works on any map/mod — not a mod itself, so there's nothing to add to a room's Travel entry. Start it from the console once you're in a room:

CommandWhat it does
horde_startBegins wave 1 after a short delay. Monsters spawn scattered around a random player each wave; the next wave starts a few seconds after the last monster dies.
horde_stopEnds it.
horde_statusPrints the current wave, how many monsters are still alive, and the active difficulty cvar values. Read-only — anyone can check, not just the host.

Difficulty is tunable — like any server cvar (sv_gravity, teamplay, ...), only the room's privileged host can change these, and a chosen value is remembered across restarts:

CvarDefaultControls
sv_horde_startdelay3Seconds after horde_start before wave 1.
sv_horde_wavedelay8Seconds between a wave clearing and the next one starting.
sv_horde_basecount3Monsters in wave 1.
sv_horde_growth1Extra monsters added per wave after that.
sv_horde_maxsize16Hard cap on monsters in a single wave.
sv_horde_healthgrowth0.04Fractional monster health increase per wave (0.04 = +4%/wave) — makes later waves tougher, not just bigger.
Example: sv_horde_wavedelay 15 gives the group more breathing room to loot/heal between waves. sv_horde_growth 2 ramps up faster for a shorter, more intense run.

Admin Guide

If you're running the server, the day-to-day stuff all lives in admin.html — no command line needed after initial setup.

Accounts

Add, delete, reset passwords, and grant/revoke admin from the Users section. There's no self-signup by design — you hand out credentials to whoever you invite.

Maps

The Maps section controls exactly what shows up in maps.html and the in-game Travel menu:

  • Rename — edit the Title field. The ID (e.g. frogsbog) can't change once created, since it has to match the actual map file.
  • Hide/show — the Visible/Hidden toggle. Hidden maps stay in the catalog for you to bring back later, they just don't show to players.
  • Add a map — you'll need the map's ID (its filename minus .bsp), and if it needs a mod, the mod dir(s) to layer in (e.g. mods/copper).

Rooms

See who's connected where and terminate a room if needed (the Hub itself can't be terminated — it just comes back empty on the next restart, so there's no point).

Command-line fallback

If the server's down and you need to bootstrap the first admin account:

cd server
deno run --allow-read --allow-write --unstable-kv manage_users.ts add yourname yourpassword --admin

Full setup/deployment instructions are in server/README.md in the repo.

FAQ

I can't log in / it says "Could not reach the server"

The lobby server isn't running or isn't reachable. Ping the admin.

The screen went black / I got kicked back to the main menu

The room you were in probably ended (empty rooms get cleaned up after a while, except the Hub). Just log back in — you'll land in the Hub with your progress intact.

Can I lose my progress?

Only if you leave while dead — dying and disconnecting doesn't save a 0-health state, so you'll respawn fresh next time rather than stuck dead.

Do I need Discord/voice chat set up in-game?

No — this project leans on whatever voice chat your group already uses (Discord, etc). The game's own text chat (T) works too if you'd rather type.

Something's broken / a monster won't die / I'm stuck

noclip gets you unstuck, god gets you through a rough fight, and worst case disconnect then reconnect resets your position (not your saved stats).
